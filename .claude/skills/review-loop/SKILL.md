# 검토 루프

기준 브랜치: $ARGUMENTS (비어 있으면 main)

## 규칙
- 서브 에이전트에서 코드를 고치게 하지 않습니다.
- blocker·major가 없으면 멈추고 표를 보여 준다. 
  있으면 그 항목만 고치고 uv run pytest -q를 돌린 뒤, 회차 번호를 올려 1번부터 다시 한다.
  minor는 고치지 않고 표에만 남긴다. 3회차가 끝나도 남으면 더 고치지 말고 '사람 확인 필요'로 정리한 뒤 멈춘다.

## 할 일
1. 변경을 파일로 남긴다.
   `(과제의 명령. main 자리는 기준 브랜치)`
2. (리뷰어 셋을 부르는 방법: 한 메시지, 동시에, 다 받을 때까지)
   검토 요청문: "(고정 문장 한 줄)"
3. (결과를 합치는 방법: 표 머리, 중복 처리)
4. (5단계는 여기까지: 표를 보여 주고 멈춘다)
